# 주유소 상표 이미지

주유소 상세·지도 마커에서 실제 상표를 식별하기 위한 원본 이미지다. kor-travel-transport
(`packages/kor-travel-transport-admin/frontend/public/fuel-brands/`)가 보관한 파일을 바이트 그대로
복사했다(같은 git blob). 직접 그린 로고가 아니며 색상·종횡비·로고 구성을 바꾸지 않는다.
상표권과 이미지 저작권은 각 권리자에게 있다.

원 출처는 한국석유공사 오피넷의 주유소 상표 이미지(`https://www.opinet.co.kr/images/user/com/`)이고,
상표 코드·이름·파일 연결은 transport 쪽 README가 정본이다. 코드 → 파일 표는
`packages/domain/src/fuelStation.ts`의 `fuelBrand`가 갖는다(ETC 자가상표는 공통 로고가 없어 일반 주유기 아이콘).

오피넷의 저작권정책은 포괄적인 자유 재배포 허가가 아니다. 이 파일들은 프로젝트의 라이선스로
재허가하지 않으며 상표 식별 목적으로만 쓴다. 색상 변경·부분 삭제·홍보용 재사용을 하지 않는다.
