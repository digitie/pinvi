# #671·#672 공유 복귀·관리자 거절의 세션 경계

## 범위

- #643 최신 운영 카탈로그 댓글의 보안 후속 두 건을 묶는다.
- 공유 토큰을 로그인 next URL·prefetch·OAuth 저장 상태로 전달하지 않는다.
- 정상 공유 comment/edit 로그인 후 같은 공유 화면 복귀와 초안 보존 정책을 유지한다.
- 관리자 로그인 거절은 세션 종료 완료 후 표시한다. 종료 실패를 성공처럼 숨기지 않는다.
- 기존 refresh와 logout/login의 경합을 재현하고, 확인된 경합을 공통 세션 변경 경계에서 보완한다.

## 구현·검증 순서

1. 현재 공유 로그인 링크와 관리자 거절 완료 시점, refresh 경합을 실패 우선 테스트로 고정한다.
2. 공유 복귀는 동일 탭의 만료·일회성 브라우저 저장과 토큰 없는 안전한 복귀 경로를 사용한다. 모든 서버 복귀 검증에서도 원본 토큰 경로를 배제한다.
3. 관리자 거절은 logout 완료·캐시 정리 이후 표시하고 실패 시 정리 실패·재시도를 제공한다.
4. 실제 WSL API·브라우저에서 토큰 URL 유출 없음·동일 공유 복귀·거절 후401과 경합을 확인한다. 운영 suite의 origin guard는 유지한다.
5. 독립 전문 적대적 리뷰2인과 최종 SHA CI 확인 후 일반 squash merge한다.

## 실행 경계

- Draft PR을 먼저 만들고 관련 구현을 자주 remote에 커밋한다.
- WSL 전용이며 운영 접근·배포·테스트는 하지 않는다. 최종 운영 검증은 Claude Code가 담당한다.
- 운영 값·토큰 원문·자격 증명은 커밋하지 않는다. Telegram 등 외부 실제 메시지를 보내지 않는다.
