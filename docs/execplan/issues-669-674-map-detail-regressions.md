# #669·#674 지도 선택·팝업·상세 회귀

## 범위

- #671/#672는 다른 Code가 진행 중이라는 사용자 지시에 따라 건너뛴다. 중복 draft676은 닫고 로컬 수정은 stash로 보관했다.
- #669 선택한 두 외부 보강을 단일 상세 예산 안에서 병렬 실행한다. 이미 완료된 결과를 보존하고 미완료만 저하로 표시하며 요청 순서를 유지한다.
- #674 검색 결과 선택의 실제 이동, 모바일 여행 전체 맞춤 범위, 교통 패널에 가려지는 popup 닫기를 재현한다.
- 제품 결함과 오래된 fixture·대기 조건의 잘못을 구분한다. 데이터가 맞지 않는 합격 조건을 단순 완화하지 않는다.

## 순서와 검증

1. API 보강의 동시 시작·시간 예산·부분 결과·취소·순서 회귀를 먼저 작성한다.
2. 실제 WSL API·Chromium에서 검색 이동·여행4장소 맞춤·popup 상호작용을 확인하고 재현한 원인을 수정한다.
3. 관련 카탈로그를 실제 응답·카메라 완료·DOM 클릭 가능성에 연결한다. 운영 origin guard는 유지한다.
4. 의미 있는 구현을 자주 remote에 커밋한다. 최종 독립 전문 적대 리뷰2인·최종 SHA CI 후 일반 squash merge한다.

## 경계

- 기존 색상·톤·공유/숨김 정책을 보존한다.
- prod 접근·배포·운영 테스트는 하지 않는다. 최종 운영 검증은 Claude Code가 담당한다.
- 실제 Telegram 등 외부 메시지를 보내지 않는다. 원문 운영 값은 커밋하지 않는다.
