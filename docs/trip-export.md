# 여행 인쇄·PDF 저장·캘린더 내보내기

여행 상세와 읽기 권한이 있는 공유 화면의 **내보내기**에서 일정을 미리 봅니다. 선택·숨김 상태와 관계없이 현재 조회된 전체 일자와 장소를 포함합니다. 창을 연 시점의 일정으로 고정되므로 수정한 내용은 창을 닫고 다시 열어 확인합니다.

## 인쇄와 PDF 저장

**인쇄 / PDF 저장**을 누르면 별도 인쇄창에서 브라우저 인쇄 대화상자를 엽니다. 프린터 또는 PDF 저장 대상을 직접 선택합니다. PDF 파일을 자동으로 내려받는 기능은 아닙니다. 브라우저가 제공하는 머리말·바닥글·용지·배율 설정은 인쇄 대화상자에서 조정합니다.

출력에는 여행 제목·기간·설명, 일자 제목·메모, 방문 순서에 따른 장소·주소·메모·알려진 도착/출발 시각이 들어갑니다. 시각은 기기 시간대와 관계없이 한국 시각(KST)입니다. 날짜·시각 미정과 좌표 없는 장소도 본문에서 빠지지 않습니다. 긴 메모는 여러 페이지에 나누어 표시합니다.

위치 개요는 기존 지도에서 확인한 좌표와 방문 순서만 그린 정적 위치도입니다. 배경지도와 실제 도로 경로는 포함하지 않습니다. 좌표가 없는 장소는 본문 번호를 유지하고, 같은 좌표를 재방문한 번호는 하나의 표식과 설명에 함께 표시합니다.

팝업이 차단되거나 스타일·글꼴 준비가 8초 안에 끝나지 않으면 원인을 안내합니다. 준비 중에는 취소할 수 있습니다. 준비 실패 시 원래 공유 URL을 대신 인쇄하지 않습니다.

## ICS 캘린더 파일

**ICS 다운로드**는 캘린더 앱에 가져올 수 있는 파일을 내려받습니다. 날짜가 있고 시각이 없으면 종일 일정입니다. 장소가 없는 일자도 날짜가 있으면 하나의 종일 일정으로 포함합니다. 도착과 출발 중 확인된 시각만 사용하고 출발만 있으면 그 시각부터 시작하는 일정임을 설명합니다. 종료 시각이 시작보다 이르거나 같으면 종료를 넣지 않고 건수를 안내합니다.

날짜와 시각이 모두 미정이면 캘린더에서 제외한 건수를 표시합니다. 포함할 일정이 하나도 없으면 다운로드 버튼을 비활성화하지만 인쇄 미리보기에서는 계속 확인할 수 있습니다. 임의 날짜·체류 시간은 만들지 않습니다.

시간이 있는 이벤트는 UTC로 저장하고, 종일 종료는 다음 날을 배타적 종료로 기록합니다. 줄 끝·텍스트 이스케이프·긴 한글 접기는 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html)를 따릅니다. 같은 여행의 장소를 다른 일자로 옮겨도 이벤트 UID는 유지됩니다. 캘린더 앱의 반복 가져오기/중복 처리 방식은 앱 설정에 따릅니다.

## 공유와 권한

기존 화면이 조회 권한으로 받은 일정 필드만 복사합니다. 동행자·댓글·첨부·사용자 외부 URL과 공유 token을 파일에 포함하지 않습니다. 인쇄창은 token 없는 about:blank이고 원래 창 연결을 끊으며 Next 정적 CSS 요청에 referrer를 보내지 않습니다.

공유 여행 또는 token이 바뀌면 이전 내보내기를 닫습니다. 만료·철회되어 거절된 공유 화면에는 내보내기를 표시하지 않습니다. 공유를 철회하더라도 이미 전달했거나 저장한 파일까지 회수할 수는 없습니다.
